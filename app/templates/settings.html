telegram

push-nachricht an einen chat oder eine gruppe
anleitung: bot-token & chat-id besorgen
  1. In Telegram @BotFather öffnen, /newbot senden, namen vergeben → BotFather antwortet mit dem bot-token (sieht aus wie 123456789:AAH…).
  2. Dem neuen bot eine beliebige nachricht schicken (er antwortet nicht — egal).
  3. Im browser https://api.telegram.org/bot<TOKEN>/getUpdates öffnen → in der antwort steht "chat":{"id":123456789} — das ist die chat-id.
  4. Mehrere leute? Eine telegram-gruppe erstellen, den bot hinzufügen, in der gruppe etwas schreiben und wieder getUpdates aufrufen — gruppen-ids sind negativ (z. B. -100123…).

email (resend)

mail an beliebig viele adressen
anleitung: resend einrichten
  1. Kostenloses konto auf resend.com anlegen.
  2. Unter API Keys einen key erstellen (beginnt mit re_) und hier eintragen.
  3. Unter Domains die eigene domain verifizieren (DNS-einträge setzen) — die from-adresse muss zu dieser domain gehören.
  4. Nur zum ausprobieren geht auch onboarding@resend.dev als from-adresse, damit darf aber nur an die eigene account-email geschickt werden.
